# codomax-day14-student-performance-analysis
# Codomax AI/ML Internship – Day 14

## 📌 Project
Student Performance Analysis

## 📖 Description
This project analyzes student academic performance using Python, Pandas, NumPy, and Matplotlib. It calculates summary statistics, performs branch-wise analysis, and generates an analysis report.

## 🚀 Features

- Load CSV dataset
- Display dataset information
- Calculate average, highest, and lowest marks
- Branch-wise performance analysis
- Generate analysis report

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
